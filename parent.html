Politique de confidentialité

Application « Suivi Scolaire » — Dernière mise à jour : 13 novembre 2026

1. À quoi sert l'application

« Suivi Scolaire » est une application pour les parents. Elle permet de suivre son enfant à l'école : recevoir les messages de l'école (absences, convocations, communiqués), écrire à l'école et consulter l'historique des paiements des frais scolaires.

L'application s'adresse aux parents et aux tuteurs. Elle n'est pas faite pour être utilisée par les enfants.

2. Les informations que nous utilisons

  • Informations de l'élève (données par l'école) : identifiant (ID), nom, post-nom, prénom, classe, section, nom et code de l'école, année scolaire.
  • Messages : les messages envoyés par l'école au parent et les messages que le parent écrit à l'école.
  • Historique des paiements : les montants payés et restants des frais scolaires, mois par mois, enregistrés par l'école.
  • Code de notification du téléphone : un code technique (Firebase Cloud Messaging) et le type de téléphone (Android ou iOS), pour pouvoir envoyer les notifications.

Nous ne demandons pas votre position, vos contacts, vos photos, votre micro ni votre appareil photo.

3. Pourquoi nous utilisons ces informations

  • Pour afficher votre enfant et les informations de son école dans l'application.
  • Pour vous envoyer les messages de l'école et les notifications, surtout les messages urgents.
  • Pour transmettre vos messages à l'école.
  • Pour vous montrer l'état des paiements des frais scolaires.

Nous n'utilisons pas ces informations pour la publicité.

4. Où sont gardées les informations

  • Sur votre téléphone : la liste de vos enfants, une copie des conversations et les messages en attente d'envoi, pour que l'application s'ouvre vite et marche aussi sans internet.
  • Sur notre serveur : les informations de l'école, les messages et l'historique des paiements. Les échanges entre l'application et le serveur passent par une connexion sécurisée (HTTPS).

5. Avec qui les informations sont partagées

  • L'école de votre enfant : elle voit les messages que vous lui écrivez. C'est elle qui nous fournit les informations de l'élève.
  • Google (Firebase) : pour envoyer les notifications sur votre téléphone.
  • Notre hébergeur de serveur : il garde les données pour nous, sans les utiliser pour lui-même.

Nous ne vendons pas vos informations et nous ne les donnons à personne d'autre.

6. Vos choix et la suppression de vos données

  • Retirer un enfant : dans l'application, appuyez longtemps sur l'enfant puis choisissez « Retirer de ma liste ». Les conversations gardées sur votre téléphone sont effacées et ce téléphone ne reçoit plus ses notifications.
  • Notifications : vous pouvez les désactiver à tout moment dans les paramètres de votre téléphone.
  • Supprimer vos données sur le serveur : écrivez-nous à l'adresse ci-dessous. Précisez le nom de l'élève et le nom de l'école. Nous répondrons le plus vite possible.

Les informations de l'élève qui appartiennent au dossier de l'école (inscription, paiements) sont gérées par l'école. Pour les modifier, contactez directement l'école.

7. Les enfants

L'application est utilisée par les parents. Les informations d'un enfant ne sont ajoutées que si le parent entre l'ID donné par l'école.

8. Changements

Si nous changeons cette politique, la nouvelle version sera publiée sur cette page avec une nouvelle date.
